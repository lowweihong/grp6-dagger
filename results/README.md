This folder contains all consolidated experimental results, logs, outputs, and videos for the DAgger reimplementation project.

│   │   ├── log_*.log
│   │   └── videos_*/
│   ├── dagger/
│   │   ├── results_*.txt

## Contents

Each method folder contains:
- **Results files** (`results_*.txt`): Performance metrics (rewards, fall counts, etc.)
- **Log files** (`log_*.log`): Training logs
- **Videos** (`videos_*/`): Evaluation episode recordings (MP4 format)

## Key Metrics

All key metrics are generated by the `check-performance.ipynb` notebook, which reads from this consolidated location.

## Modification Experiments

The `modification/` folder contains experimental results for a modified DAgger implementation with:
- **KDE-based trajectory filtering**: Filters trajectories from well-explored regions
- **Action noise**: Adds Gaussian noise to student actions for exploration

These experiments compare modified DAgger vs vanilla DAgger across different iteration counts (10, 15, 20, 25, 30, 35, 40). See [`dagger_implementations_kde/`](../dagger_implementations_kde/) for implementation details.
